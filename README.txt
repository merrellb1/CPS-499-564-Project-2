How to run code:

Problem 1:
Go to problem1.m and run it, this will output figures of the original images
and each of the importance maps. Running the code also saves the importance maps into a folder in Results/problem1_results.


Problem 2:
Go to problem2.m and run it, this will output figures of the original images
and each of the context aware importance maps. Running the code also saves the context aware importance maps into a folder in Results/problem2_results.

Problems 3 and 4:
Go to problem3.m and run it. As long as everything's in the correct folder, it'll run for a few minutes and place the results into Results/problem3_results and Results/problem4_results
